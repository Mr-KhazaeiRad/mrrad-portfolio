رزومه محمد خزائی راد
====================

برنامه‌نویس سی‌شارپ، بازی‌ساز و طراح و توسعه‌دهنده وب
چند سال تجربه در برنامه‌نویسی، بازی‌سازی و طراحی و توسعه وب‌سایت‌های تعاملی.

مهارت‌ها: سی‌شارپ (C#)، منطق بازی، HTML، CSS، JavaScript، Tailwind CSS، طراحی واکنش‌گرا، Web API، localStorage، GitHub و GitHub Pages.
